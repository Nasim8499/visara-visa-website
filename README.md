# Visara — Apple-style visa & immigration website

Single-page React + Vite + Tailwind 4 site with a liquid-glass navigation, category pages
(Work, Student, Family, Passport…) and a single-file production build.

```sh
npm install
npm run dev      # local
npm run build    # dist/index.html (self-contained)
```

Deployed on Vercel — framework auto-detected, output `dist`.
